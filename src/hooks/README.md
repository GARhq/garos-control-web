# hooks

## 📌 Visão Geral
Módulo integrante da arquitetura do repositório GAROS no caminho `garos-control-web/src/hooks`.

## ⚙️ O que esta pasta faz
- Fornecer a lógica executável de backend, ferramentas CLI ou componentes de alta performance em Rust.
- Implementar componentes interativos de interface de usuário e gerenciamento de estado web.

## 📂 Conteúdo e Arquivos Detalhados
- `useDashboardLayout.ts`: **[Componente/Módulo TS/JS]** — Implementação TypeScript/React exportando exports `useDashboardLayout` e hooks React `useDashboardLayout, useState`.
- `useDeviceType.ts`: **[Componente/Módulo TS/JS]** — Implementação TypeScript/React exportando exports `DeviceType, UseDeviceTypeReturn, useDeviceType` e hooks React `useDeviceType, useState`.
- `useGarosRealtime.ts`: **[Componente/Módulo TS/JS]** — Implementação TypeScript/React exportando exports `useGarosRealtime` e hooks React `useGarosStore, useGarosRealtime`.
